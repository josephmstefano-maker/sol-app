Privacy policy

Last updated: October 6, 2026

SOL is personal assistant software that runs on its owner's own computer and is used only by its owner. This policy explains what Google user data SOL accesses and how it is handled.

Data SOL accesses

Only with the owner's explicit consent through Google's sign-in screen, SOL may access the owner's own Google account using these permissions:

  • Gmail metadata (gmail.metadata): message headers such as sender, subject, date and labels, used to understand and sort incoming mail.
  • Gmail read-only (gmail.readonly), only if the owner enables it: message text, used to sort mail more accurately. Attachments are not downloaded.
  • Gmail modify (gmail.modify): used only to apply labels and archive messages after the owner approves each change. SOL never deletes email and never sends email.
  • Google Calendar (calendar), only if the owner enables it: used to show and, with the owner's approval, manage the owner's own events.

How the data is used

Google user data is used only to provide SOL's features to its owner: suggesting how to sort mail, carrying out sorting the owner approved, and answering the owner's questions about their own mail and calendar.

To produce sorting suggestions, SOL may send limited message information (such as sender, subject and a short text snippet) to the AI model provider the owner has configured (currently OpenAI's API, or a model running locally on the owner's computer). It is sent only to generate suggestions for the owner and is not used to train AI models.

Storage and retention

SOL stores the data it needs (message identifiers, headers, sorting suggestions and the record of the owner's approvals) locally on the owner's computer. Message text read for sorting is not kept. The owner can delete SOL's local data at any time.

Sharing

SOL does not sell Google user data, does not use it for advertising, and does not share it with anyone other than the AI model provider described above. No person other than the owner has access to it.

Google API Services User Data Policy

SOL's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

The owner can remove SOL's access at any time at myaccount.google.com/permissions.

Contact

Questions can be sent to the support email address shown on SOL's Google sign-in screen.
